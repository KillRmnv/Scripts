# Установка: Обзор компонентов

Этот набор скриптов превращает чистую систему (Arch Linux / Debian / Ubuntu) в полноценную рабочую станцию разработчика.

## Категории устанавливаемого ПО

### 1. Системные утилиты
| Пакет | Назначение |
|-------|------------|
| `curl`, `wget` | Загрузка файлов, работа с API |
| `gnupg` | Шифрование, подпись пакетов |
| `git` | Система контроля версий |
| `net-tools` | Классические сетевые утилиты (ifconfig, netstat) |
| `tree` | Древовидный вывод структуры каталогов |
| `bat` | Красивый аналог cat с подсветкой синтаксиса |
| `ripgrep` (rg) | Быстрый поиск по файлам |
| `fd` | Удобная замена find |
| `fzf` | Fuzzy-поиск в терминале |
| `pass` | Менеджер паролей (CLI) |
| `jq` | Обработка JSON в терминале |
| `chafa` | Консольный рендеринг изображений |
| `git-lfs` | Git Large File Storage |
| `flatpak` | Универсальная система пакетов |
| `gnome-software` | Магазин приложений GNOME |

### 2. Разработка (Языки и SDK)
| Пакет | Назначение |
|-------|------------|
| `python` (3.x) | Язык программирования Python |
| `python-pip` | Пакетный менеджер Python |
| `python-virtualenv` | Изолированные окружения Python |
| `jdk21-openjdk` | Java Development Kit 21 |
| `jdk-openjdk` | Java Development Kit (последняя версия, 25) |
| `maven` | Система сборки Java проектов |
| `gradle` | Альтернативная система сборки Java/Kotlin |
| `nodejs-lts-jod` | Node.js v22 LTS (JavaScript runtime) |
| `npm` | Пакетный менеджер Node.js |
| `rustup` + `cargo` | Язык Rust и его пакетный менеджер |
| `cmake` | Кроссплатформенная система сборки |
| `ninja` | Быстрая система сборки |
| `meson` | Система сборки (альтернатива CMake) |

### 3. Базы данных
| Пакет | Назначение |
|-------|------------|
| `postgresql` | Объектно-реляционная СУБД |
| `pgadmin4` | Веб-интерфейс для управления PostgreSQL |

### 4. Текстовые редакторы и IDE
| Пакет | Назначение |
|-------|------------|
| `neovim` | Современный Vim-редактор |

### 5. Терминал и Shell
| Пакет | Назначение |
|-------|------------|

## Итог
После выполнения всех скриптов вы получаете:
- **Окружение разработчика**: Java, Python, Node.js, Rust
- **Современный стек терминала**: Fish + Starship + Kitty/Ghostty
- **Мощные редакторы**: Neovim, Zed
- **AI-инструменты**: OpenCode, Qwen, Mistral, Cline
- **Системные утилиты**: Docker, Git, мониторинг, поиск
- **Оконный менеджер**: Hyprland (Wayland)
